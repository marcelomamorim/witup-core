# WITUp
WITUp is a static analyser that determines the conditions that can cause Java methods to throw.

## Local vs. global expaths
Local expaths describe exception paths inside a single method, including the path condition that
leads to a `throw`. Global expaths lift those local paths to an interprocedural view by composing
path conditions across calls and tracking the call stack. Today, the global expath generator
expands local expaths directly when no calls are involved, and it provides the hooks for future
interprocedural composition.

## Running tests
```bash
mvn test
```

## Current limitations
* Global expaths are currently generated by lifting local expaths when no interprocedural calls
  are involved. Future work will inline path conditions across call chains.
* Test coverage currently targets Java bytecode only; additional JVM languages can be added when
  test tooling is configured for them.
